# Mo Famiz Productions — Mobile-first HTML (Dynamic)

## Deploy to Vercel (no build)
1) Upload this folder to GitHub
2) Import repo in Vercel → Deploy

## Dynamic parts
- Portfolio loads from: /data/tracks.json
- Booking form posts to: /api/book

## Customize
- Replace logo: /assets/MFP2.png
- Edit links: /data/tracks.json
